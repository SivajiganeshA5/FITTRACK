# FITTRACK Android
Offline-first fitness tracker. Includes the 60-day workout checklist, body measurements, calendar, reports, and local JSON backup. Walking and running are started manually with separate buttons. Distance is GPS-based, duration is measured during the session, and steps are counted when the device has a step-detector sensor. GPS runs only during an active session. Fitness records are stored locally; no cloud upload is implemented.

Build with Codemagic using the included codemagic.yaml. Debug APK artifact: app/build/outputs/apk/debug/*.apk.
